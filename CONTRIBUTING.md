# Работа над проектом

## Ветки

- `main` — стабильная версия;
- задачи выполняются в отдельных ветках;
- формат: `feature/<issue>-short-name`, `fix/<issue>-short-name`, `docs/<issue>-short-name`.

## Pull Request

Каждая существенная задача завершается Pull Request.

В PR указывается:
- какая задача решена;
- что изменено;
- как проверить;
- ссылка на Issue.

## Review

Желательно, чтобы изменения одного участника просматривал другой участник команды.

## Статусы

```text
Backlog -> Ready -> In Progress -> Review -> Done
```

## Definition of Done

Задача считается завершённой, когда:
- реализован заявленный scope;
- код собирается;
- основные сценарии проверены;
- документация обновлена при необходимости;
- изменение прошло review и попало в main.
