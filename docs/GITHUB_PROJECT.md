# Задачи и доска проекта

Основная точка входа — [план проекта #4](https://github.com/flex12312/agent-observatory/issues/4). Он содержит десять задач первой версии и ссылку на идеи для развития в #50.

## Карточка задачи

- Короткий заголовок без префиксов приоритета и названия отдела.
- Чеклист того, что нужно сделать.
- Проверяемый критерий готовности.
- Зависимости от других задач.
- Автор и ревьюер выбираются перед началом работы.

В команде три участника со смешанным распределением. Постоянного закрепления backend, frontend или SDK за людьми нет.

## Статусы

- Запланировано — задача ещё не начата.
- В работе — есть исполнитель и текущая работа.
- На проверке — открыт PR для review.
- Готово — критерии проверены и реализация принята.

Закрытые старые карточки помечены как неактуальное планирование и ссылаются на замену. Они не считаются выполненной функциональностью.

## Доска GitHub Projects

Доска необязательна. Если используем её, достаточно полей Status и Assignee и колонок по статусам выше. Без доски работаем по списку открытых Issues и плану #4.

Технические зависимости и соответствие шагов карточкам: [план реализации](IMPLEMENTATION_PLAN.md).
